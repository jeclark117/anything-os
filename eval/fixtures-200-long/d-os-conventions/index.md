# Example Co. OS

A one-person design studio: clients, the business, admin, and marketing. **Start with [CLAUDE.md](CLAUDE.md).**

# Areas

* [clients/](clients/) - One note or folder per client, plus leads.
* [admin/](admin/) - Insurance, taxes, money, tools, and contracts.
* [business/](business/) - Rates, capacity, goals, ideas, contacts, and how the week runs.
* [marketing/](marketing/) - Ads, Instagram, the portfolio, the studio's own site and brand.
* [process/](process/) - How the studio runs a project, from proposal to archive.
* [learning/](learning/) - Courses, books, and things to learn.

# Other

* [todo.md](todo.md) - Running to-do list.
* [conventions.md](conventions.md) - The rules every file follows.
* [log.md](log.md) - Changes to how this OS is set up.
