# anything-os

A template for building your own OS: a folder of plain notes that you and your AI agent keep up together. **Start with [START.md](START.md).** Your agent reads it, asks you a few questions, and builds the rest.

# Setup

* [START.md](START.md) - The guided setup. The agent reads it, interviews you, and builds your OS.
* [conventions.md](conventions.md) - The rules every file follows. Written for the agent.
* [writing-samples.md](writing-samples.md) - How to pick a few things you've written so your agent can learn to write like you.

# Reference

* [examples/](examples/) - Three finished shapes: a household, a small business, and a garden.
* [scripts/check.sh](scripts/check.sh) - Optional. Checks the folder against the rules from a terminal.
